# data

테스트 질문, 선택지, 결과 설명처럼 화면에 사용할 데이터를 보관합니다.

향후 질문 데이터를 추가할 때 테스트 버전도 함께 관리하여,
답변과 결과가 어떤 버전의 테스트에서 나왔는지 구분할 수 있도록 합니다.
데이터의 TypeScript 타입은 `src/types`에서 정의합니다.

현재는 구조 확인용 질문과 결과 예시를 각각 1개만 제공합니다.

- `questions.ts`: 테스트 버전과 질문·선택지·점수 변화량 예시.
- `resultTypes.ts`: 16가지 조합을 키로 사용할 수 있는 결과 목록.
- `subTraits.ts`: 보조축별 양쪽 성향 이름과 중립 태그 이름 초안.

결과 ID는 메인축 순서대로 성향을 하이픈으로 연결합니다.
결과를 추가할 때 키, `id`, `mainTraits`가 같은 조합을 나타내는지 확인하세요.
현재 타입은 각 값의 허용 범위를 검사하며 세 값의 일치 여부까지 검사하지는 않습니다.
`ResultTypeCatalog`는 작성 중인 목록이므로 일부 결과가 없어도 허용합니다.
정식 테스트 공개 전에는 16개 조합을 모두 채워야 합니다.
