# types

여러 파일에서 공유할 TypeScript 타입을 보관합니다.

타입은 질문, 선택지, 답변, 결과 등의 데이터가 어떤 모양이어야 하는지
정하는 규칙입니다. 실제 데이터는 `src/data`, 계산 함수는 `src/lib`에 둡니다.
향후 답변과 결과의 타입에는 테스트 버전을 연결할 수 있도록 설계합니다.

`test.ts`에 메인축 4개, 보조축 5개, 질문·선택지·점수 변화량,
테스트 버전이 포함된 질문 묶음, 결과 유형과 보조 태그의 타입을 정의합니다.

- union (`"combat" | "position"`): 나열한 값만 허용합니다.
- `keyof`: 객체 타입의 키들을 union으로 가져옵니다.
- `Record`: 정해진 키마다 값의 타입을 지정합니다.
- `Partial`: 모든 키를 필수로 적지 않아도 되게 합니다.
- `readonly`: 코드에서 실수로 값을 변경하는 것을 막습니다.
- `as const satisfies`: 데이터의 구체적인 값을 유지하면서 타입 규칙을 검사합니다.

이 타입 검사는 개발·빌드 시 적용됩니다. 추후 외부 API나 DB에서 받은
데이터를 검증하는 기능은 별도로 구현해야 합니다.
